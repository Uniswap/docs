| Hook | Core Mechanism | Primary Technology | Get Started |
| :--- | :--- | :--- | :--- |
| **Aggregator Hooks** | Routes swaps through external liquidity sources in a hook. | External Liquidity Aggregation | [Link](https://github.com/Uniswap/v4-hooks-public/tree/main/src/aggregator-hooks) |
| **Permissioned Pools** | Restricts swaps and liquidity provision to allowlisted addresses. | ERC6909 Wrapped Token Proxy | [Link](/docs/protocols/uniswap-labs-hooks/permissioned-pools/overview) |
| **StablePair Hook** | Concentrates liquidity around a reference price for assets that should trade at a fixed rate. | Custom Pricing Logic | [Link](/docs/protocols/uniswap-labs-hooks/stable-pair/overview) |
| **VolatilePair Hook** | Sets a separate fee for each swap direction based on recent price moves, for volatile pairs. | Custom Pricing Logic | [Link](/docs/protocols/uniswap-labs-hooks/volatile-pair/overview) |
| **Wrapper Hook** | Wraps and unwraps ERC-4626 vault shares against their underlying asset at the vault's own exchange rate, in a hook. | Wraps core conversion contract | [Link](/docs/protocols/uniswap-labs-hooks/erc4626-wrapper/overview) |
| **WETH &lt;&gt; ETH** | Facilitates WETH &lt;&gt; ETH conversions in a hook. | Wraps core conversion contract | [Link](https://github.com/Uniswap/v4-hooks-public/blob/main/src/WETHHook.sol) |
| **wstETH &lt;&gt; stETH** | Facilitates wstETH &lt;&gt; stETH conversions in a hook. | Wraps core conversion contract | [Link](https://github.com/Uniswap/v4-hooks-public/blob/main/src/WstETHHook.sol) |

For bespoke infrastructure or custom asset class support, [get in touch](/uniswap-labs-hooks) with our team.

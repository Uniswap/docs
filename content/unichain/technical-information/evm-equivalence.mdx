## Differences Between Unichain and Ethereum Mainnet
As an OP Stack chain, Unichain is EVM-equivalent with minimal changes to standard Ethereum behavior. Read more about OP Stack and Ethereum mainnet differences in the [OP Stack docs](https://docs.optimism.io/op-stack/protocol/differences).

## Gas & EIP-1559 Configuration
| Parameter | Unichain | OP Mainnet | Ethereum value |
| -- | -- | -- | -- |
| Block time in seconds | 1 | 2 | 12 |
| Block gas limit | 60,000,000 | 40,000,000 | 60,000,000 |
| Block gas target | 5,000,000 | 20,000,000 | 30,000,000 |
| EIP-1559 elasticity multiplier | 12 | 2 | 2 |
| EIP-1559 denominator | 250 | 250 | 8 |

These values can change through network upgrades and chain configuration updates. To read the current values, query the latest block with `eth_getBlockByNumber`: the block gas limit is in `gasLimit`, and on OP Stack chains the EIP-1559 denominator and elasticity are encoded in `extraData`.

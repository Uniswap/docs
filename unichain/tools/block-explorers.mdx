## Uniscan

Uniscan provides tools to help you view transaction data and debug smart contracts:

- Search by address, transaction hash, batch, or token
- View, verify, and interact with smart contract source code
- View detailed transaction information
- View L1-to-L2 and L2-to-L1 transactions
- Visit the [Uniscan Docs](https://docs.uniscan.xyz/) for details

### Supported networks
- [Uniscan](https://uniscan.xyz/)
- [Uniscan Sepolia](https://sepolia.uniscan.xyz/)

## Blockscout

Blockscout provides tools to help you view transaction data, interact and debug smart contracts, and see chain analytics:

- Search by address, transaction hash, batch, or token
- View, verify, and interact with smart contract source code
- View detailed transaction information
- View L1-to-L2 and L2-to-L1 transactions
- Visit the [Blockscout Docs](https://docs.blockscout.com/) for details

### Supported networks
- [Unichain Mainnet](https://unichain.blockscout.com/)
- [Unichain Sepolia](https://unichain-sepolia.blockscout.com/)

### PRO API

Blockscout's PRO API delivers fast, reliable access to optimized Unichain data.

- 5 RPS and up to 5,000 calls/day on the free tier
- Higher RPS and call allowances on paid tiers
- Manage API keys and view usage metrics on the [Developer portal](https://dev.blockscout.com)
- Visit the [PRO API docs](https://docs.blockscout.com/devs/apis/pro-api) for details
